GitHub Pages deployment

1. Create a new public GitHub repository. A simple name like `applied-ai-portfolio` is fine.
2. Upload `index.html`, `styles.css`, and your resume PDF (`rESUME_FIXED.pdf`) into the repo root.
3. In the repo, go to Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Wait a minute or two. GitHub will publish a URL like:
   `https://CaraOuellette.github.io/applied-ai-portfolio/`
7. Open the site and make sure all links work.
8. Submit that URL to D2L.

Optional but recommended improvements before submitting

- Replace any placeholder "Link target" text in the Projects section with real GitHub or Substack links.
- Add a redacted unofficial transcript PDF only if you are comfortable making it public.
- Add your George Brown certificate once it is issued.
- If you want a custom domain later, GitHub Pages supports it, but do not bother for this assignment.

Files in this starter

- `index.html` -> the portfolio page
- `styles.css` -> the site styling
- `rESUME_FIXED.pdf` -> expected resume filename for the "View Resume" button

Notes

- This is a one-page portfolio optimized for speed and the assignment rubric.
- If you rename the resume PDF, update the two `rESUME_FIXED.pdf` links in `index.html`.
